# Como contribuir

1. Abra uma issue descrevendo o problema ou melhoria.
2. Crie uma branch a partir de `main`.
3. Mantenha a alteração pequena e focada.
4. Adicione ou atualize testes.
5. Execute `npm run check` e `npm test`.
6. Abra um Pull Request explicando o motivo e o impacto da mudança.

Evite incluir dados reais, credenciais, informações corporativas ou dependências sem justificativa técnica.
