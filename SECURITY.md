# Política de segurança

Não publique vulnerabilidades em issues abertas.

Ao relatar uma falha, informe:

- Versão ou commit afetado.
- Passos mínimos para reprodução.
- Impacto estimado.
- Possível correção, quando conhecida.

O API Impulse bloqueia destinos privados por padrão, mas não deve ser exposto publicamente com `ALLOW_PRIVATE_TARGETS=true`.
